# Keep SPEC CPU 2017 out of the repository

SPEC CPU 2017 is licensed software. The license does not permit the repository to contain the suite. A reportable run of the suite takes more time than the delivery window allows on 2 OCPUs. The repository can contain the method. It can contain a result only when the result is labelled as an Estimate under the SPEC fair-use rules. The CPU Test in the first milestone uses `openssl speed`.
